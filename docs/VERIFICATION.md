# Проверка результата

Проверено 6 ноября 2026 года.

- Sass 1.94.0 скомпилировал модульный SCSS; сборка сформировала 6 тем, 18 товаров и 8 начальных операций.
- Все 3 автоматические проверки чистой логики прошли: совместный поиск и категория, сортировка без изменения исходных данных, переходы статусов.
- В Microsoft Edge проверены стартовая страница и все три работы при ширинах 320, 390, 700 и 1440 px. Горизонтального переполнения страницы нет.
- №1: якорь расписания, отклонение пустой формы и успешная проверка заполненной формы.
- №2: 18 карточек, 6 товаров категории «Курсы», сортировка по убыванию цены, пустая выдача и сброс фильтров.
- №3: открытие modal, предупреждающий toast при неверном вводе, добавление девятой операции, последовательная смена статуса и блокировка после «Готово».
- Название с HTML-тегом добавляется как текст и не создаёт HTML-элементы.
- При искусственном сбое загрузки notifications.json отображается предупреждение.
- В обычных сценариях браузер не зарегистрировал исключений JavaScript или HTTP-ошибок.
- Скриншоты overview.png и practice-01/02/03-mobile.png находятся рядом с этим отчётом.

Ограничения: проверялся Edge; другие браузеры и экранный диктор отдельно не проверялись. Полных текстов заданий в архивах не было. GitHub и GitHub Pages ещё не публиковались.
